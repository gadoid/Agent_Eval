# 出口单证与放单规则

## 1. 电放（Telex Release）
- 电放的前提：货物仍在本方掌控（收齐尾款）后，放单给买方快速提货。
- 电放的操作：向船东/货代出具电放保函，全套正本提单交回承运人注销，收货人凭身份或提单副本即可提货。
- 电放的本质：放弃正本提单的物权凭证功能。电放后无法再凭正本控货，货款未收齐时货权已经让出。
- 适用判断：货款结清后可用电放加快提货；收款安排存在不确定时，先与用户确认底线再操作。用户坚持时，说明风险与最低限度保护措施（部分预付、中信保、保兑），并保留意见。

## 2. 正本提单控制
- 凭正本提货，卖方收到尾款前牢牢控制正本，不先寄正本给买方或买方指定的货代。
- To order（指示）提单比记名（straight）提单更利于卖方控货：部分法域记名提单收货人凭身份即可提货，正本在手也可能失控；收款没把握时优先出指示提单。
- 需要向买方证明货物已出运时，发提单副本（copy B/L）或扫描件，不发正本。

## 3. 单单一致
- 同一票货的全部单据（PI、CI、PL、B/L、报关单、原产地证），买卖双方名称、货描、HS 编码、数量、毛净重、体积、金额必须完全一致。
- 常见拒付与清关延误根源：发票货描与信用证不符、箱单毛重与提单不符、客户名称拼写错误。
- 单证不一致的处置：出运前改单重出；出运后联系船东/货代/海关改单或按对方要求出具保函，不得"差异不大"直接放行。

## 4. 交单收尾款流程
- 出运后第一时间发提单副本给买方并催尾款；尾款到账后再电放或寄正本。
- 跟单节点：开船后发提单副本 → 收齐尾款 → 电放或寄正本 → 归档全套单证。
- 催款沟通附 PI 号/合同号与到期日，写明"款项到账前单据由我司保管"。

## 5. 单证风险处置
- 更改收款账户的邮件必须电话/视频与已知联系人二次核实，首笔小额测试，防冒名欺诈。
- 单证遗失（正本提单灭失）按船东流程登报声明、凭保函补发，期间暂停电放。
- 目的港弃货风险：客户拖延提货时第一时间联系货代止损（转卖、退运、拍卖），并保留催款记录。
