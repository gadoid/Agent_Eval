评测视角 · 判定配置 / 快照 / 计分规则

三件套都是身份性配置：参与会话结论的键，改任何一项都要重跑 / 重判 / 重算对应环节；下拉只切换查看口径，✎ 只改名，🔍 看详情与差异。

判定配置（条目怎么判）：编辑 scoring/operators.yaml（算子与链）→ python -m scoring.cli rejudge 重判（只调算子，不跑 agent）。

快照（拿什么题、按什么标准）：新建用例页产出 md → python evalset/md2case.py build → python -m scoring.cli specs import <dist>；切换全局当前用 snapshot use <版本>。

计分规则（判定怎么换成分）：编辑 scoring/rules.yaml → python -m scoring.cli rescore（只重算，秒级、不调算子；score/rescore/serve 会自动登记当前 rules.yaml）。

条目权重不在这里：用例详情页的权重编辑器，保存即重算本用例，无需重判；历史可查可切回。
