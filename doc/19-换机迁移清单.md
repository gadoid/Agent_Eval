## 5. 登录态与两个 profile

SparkSeed 的评测 home 是独立目录 `C:\Users\<你>\.sparkseed-eval`，与客户端 home 分开。

1. 启动 SparkSeed 客户端登录一次（写入 `~/.sparkseed/.credentials.yaml`）。
2. 把凭据复制到评测 home：
   ```bash
   mkdir -p ~/.sparkseed-eval
   cp ~/.sparkseed/.credentials.yaml ~/.sparkseed-eval/.credentials.yaml
   ```
3. 按模板建两个 profile（`evalmin` 被测、`judgee` 判定）。先让 dsh 生成目录并装依赖，再用仓库模板覆盖补丁：
   ```bash
   DSH_BIN='D:/sparkseed/sparkseed.exe --expose-internals D:/sparkseed/resources/app.asar/dsh/node_modules/@deepseek-ai/dsh-desktop-host/lib/cli.js'
   export DSH_HOME=C:/Users/<你>/.sparkseed-eval ELECTRON_RUN_AS_NODE=1
   $DSH_BIN evalmin --from-default-profile headless "只回复 OK"
   $DSH_BIN judgee --from-default-profile headless "只回复 OK"
   cp -r D:/Agent_Eval/runner/profile-templates/sparkseed-evalmin/. "$DSH_HOME/profiles/evalmin/"
   cp -r D:/Agent_Eval/runner/profile-templates/sparkseed-judgee/. "$DSH_HOME/profiles/judgee/"
   ```
   `--from-default-profile` 只负责初始化与依赖；模板覆盖的是人设/判定模型补丁（`cordis.patch.yml`），不删 `node_modules`。
4. 单发自检（判定通道的两种坏签名都在这步暴露：600s 超时、秒级全 error）：
   ```bash
   $DSH_BIN --profile judgee "只回复 OK"
   ```
   返回 `OK` 再进批量。

## 7. 重建快照与冒烟

`evalset/dist/` 不进仓库，需要重建；**必须带 `--db archive/eval.db`**，取号看库里的
`snapshots` 表，用别的库会撞号并白编译。

```bash
python evalset/md2case.py check evalset/cases
python evalset/md2case.py build evalset/cases --db archive/eval.db
```

冒烟（2 个用例，跑通执行→判定→计分）：

```bash
cd D:/Agent_Eval/runner
node lib/cli.js run --evalset ../evalset/dist/evalset-<新版本>.jsonl \
  --profile profile.sparkseed.yaml --out out/smoke --trials 1 \
  --model deepseek-v4-flash --reasoning-effort low --anchors off
cd D:/Agent_Eval
python -m scoring judge runner/out/smoke --operators scoring/operators-judge.sparkseed.yaml
python -m scoring score runner/out/smoke --operators scoring/operators-judge.sparkseed.yaml
```

## 8. 批量与复核服务

批量脚本见 `runner/s60-driver.sh`（8 配置 × 用例集，每配置两轮 judge + score）。跑之前：

- 先冒烟确认通道可用，**不要无人值守过夜**；
- 每配置跑完检查 `run.json` 的 `status_counts`，出现整批 error 立即停；
- 判定批次偶发漏条目，第二轮 judge 只补缺，属正常。

复核服务：

```bash
python -m scoring serve --db archive/eval.db --rules scoring/rules.yaml \
  --operators scoring/operators-judge.sparkseed.yaml --port 8056
```

打开 `http://127.0.0.1:8056/runs`，迁移包里的历史 run 会直接出现；对比页固定
`evalset_version=v20261030-3`（16 例批次）或 `v20261030-4`（60 例批次）。
